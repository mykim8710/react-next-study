# react-next-study

백엔드(Java/Kotlin + Spring) 개발자의 React · Next.js 학습 기록.
8주 동안 직접 코드를 치면서 배우고, 마지막에는 포트폴리오 수준의 프론트엔드 결과물을 만든다.

## 로드맵

| 주 | 주제 | 만드는 것 | 폴더 (예정) |
|---|---|---|---|
| 1 | React 핵심 | 할 일 앱 (검색 · 필터 · 정렬) | `week1-todo` |
| 2 | React 실전 | API를 붙인 검색 앱 | `week2-search` |
| 3 | Next.js 기초 | 2주차 앱을 Next.js로 옮기기 | `week3-next` |
| 4 | Next.js 풀스택 (Node) | 로그인 + CRUD 미니 앱 | `week4-fullstack` |
| 5–8 | 최종 프로젝트 | 기획 → 디자인 시스템 → 구현 → 배포 | 별도 저장소 |
| 9–10 | (선택) NestJS | API 일부를 NestJS로 다시 만들기 | `week9-nestjs` |

## 기술 스택

TypeScript · React · Vite · Next.js (App Router) · Tailwind CSS · TanStack Query · Zod · Node.js · NestJS

## 개발 환경

- Node.js: `.nvmrc` (LTS)
- 패키지 매니저: pnpm

## 규칙

- 모든 실습 코드는 직접 친다. 복붙하지 않는다.
- 수업이 끝날 때마다 커밋한다.
